# Alimente sua Mente

Site estático em português sobre grandes nomes da literatura brasileira. O projeto apresenta uma experiência visual editorial, com textos revisados, imagens dos autores e animações de rolagem.

## Visão geral

O objetivo do site é incentivar a leitura e valorizar escritores brasileiros que marcaram a cultura nacional. A página destaca:

- Machado de Assis
- Clarice Lispector
- Jorge Amado
- Euclides da Cunha
- Paulo Coelho

## Tecnologias

- HTML5 semântico
- CSS3 responsivo
- JavaScript puro
- Google Fonts
- Imagens locais do projeto

## Recursos do layout

- Hero editorial com imagem de abertura
- Paleta inspirada em papel, mata, barro e dourado
- Cards responsivos para os autores
- Animações ativadas durante a rolagem
- Suporte a `prefers-reduced-motion`
- Links externos com abertura segura em nova aba

Abra o arquivo `index.html` diretamente no navegador. O projeto não precisa de instalação, servidor local ou etapa de build.
